Entry for the [make.fun](https://make.fun/c/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c) bounty **"The Dog Ate My Homework: Funniest Excuse"**.

`main.ts` writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): the excuse a dog gives after being caught eating the homework, in the dog's own voice — it ate the evidence, so there's nothing to show, nothing to grade, and it still expects full marks.

## Run

```sh
node main.ts
```

The program validates the line (1–200 characters, no newline, not only whitespace), writes `entry.txt`, then reads it back and asserts it is byte-identical with the line.
